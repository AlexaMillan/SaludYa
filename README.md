#  SaludYa

Sistema web desarrollado para optimizar la gestión de citas médicas en consultorios y centros de salud, permitiendo administrar pacientes, médicos, especialidades y servicios de atención domiciliaria de manera eficiente.

##  Descripción

SaludYa es una plataforma diseñada para mejorar la experiencia de pacientes y personal médico mediante la automatización de procesos relacionados con la programación y administración de citas médicas.

El sistema facilita la gestión de información clínica y administrativa, reduciendo tiempos de espera y mejorando la organización de los servicios de salud.

##  Funcionalidades

- Registro y gestión de pacientes.
- Registro y administración de médicos.
- Gestión de especialidades médicas.
- Agendamiento de citas médicas.
- Reagendamiento y cancelación de citas.
- Consulta de disponibilidad de médicos.
- Solicitud de enfermería a domicilio.
- Gestión de sedes de atención.
- Administración de usuarios y roles.
- Reportes e historial de citas.

##  Instalación

1. Clonar el repositorio:

```bash
git clone https://github.com/AlexaMillan/SaludYa.git
```

2. Mover el proyecto al servidor local (XAMPP, Laragon o WAMP).

3. Crear la base de datos en MySQL.

4. Importar el archivo `.sql` incluido en el proyecto.

5. Configurar las credenciales de conexión a la base de datos.

6. Iniciar Apache y MySQL.

7. Acceder desde:

```text
http://localhost/SaludYa
```
